# Todo «Навигатор/карта» — замечания пользователя по тесту на Samsung (09.10.2026)

Исходный текст пользователя (без правок смысла), ниже — разбивка на задачи.

* При нажатии на любую точку маршрута показывать данные в ближайшей сохранённой точке: при большом масштабе расстояние между точками (интервал 5 с) большое, и по нажатию на трек информации нет — тогда показывать ближайшую точку.
* На треке выделять точки начала и окончания пути.
* На карте два компаса: один в колонке кнопок, второй вверху экрана (перекрыт названием маршрута) — верхний убрать.
* Индикатор GPS-сигнала в разделе «Поезд» не нужен, только на карте. На карте сигнал перечёркнут красным, хотя местоположение определяется правильно — проверить корректность индикатора; под индикатором подписать «GPS».
* На главном экране в разделе «Инструменты» добавить раздел «Карта» после «Календаря»; по нажатию открывает текущий поезд; если поезда или текущего маршрута нет — просто карта с текущим местоположением.
* Редактирование плеча: плечо Луга — Ультрамар: Ультрамара нет на карте, карта не открывается — нет возможности вручную указать местоположение; то же, когда станции не указаны вообще. Функционал: если станции не указаны (или указаны) — по нажатию «Карта» кнопки «Указать станцию отправления» / «Указать станцию прибытия» (или «первую/конечную»); пользователь нажимает точку на карте → поиск ближайшей станции из справочника или сохранённых станций пользователя → диалог подтверждения с кнопкой «Применить»; так же вторая станция. В полях ввода станции иконки местоположения сейчас слева — перенести в правую часть поля и сделать кликабельными: открывать шторку/экран редактирования этой станции.
* График скорости, пустое состояние: вместо «АВТО выключено…» по центру — «Для записи скорости включите режим АВТО» + кнопка включения; нет согласия — «Для записи скорости дайте согласие» + ссылка на экран согласия. Экран графика показывать ТОЛЬКО в горизонтальной ориентации (график длинный).
* Когда график показан, нажатие на точку показывает данные — хорошо; добавить возможность тянуть точку и перемещаться по соседним точкам свайпом сразу.
* Переделать цвета скорости на графике и карте: по умолчанию до 20 — зелёный, от 20 до 70 — жёлтый, свыше 70 — оранжевый, свыше 80 — красный. Если указан пассажирский поезд — красный свыше 160.

## Разбивка на исполнителей
- **A. Карта и график** (TrainMapScreen, SpeedChartScreen): пункты 1–4, график (пустое состояние, ландшафт, перетаскивание точки), цвета скорости.
- **B. Главный экран**: «Карта» в «Инструментах» после «Календаря».
- **C. Редактор плеча**: карта без станций, выбор станций по нажатию на карте с подтверждением, иконки местоположения справа и кликабельные.

## Допущения (подтвердить)
- Цвета для пассажирского поезда: зелёный до 20, жёлтый 20–120, оранжевый 120–160, красный свыше 160 (в задании сказано только «красный свыше 160»).
- Пассажирский поезд определяется по `trainCategory()` поезда (пассажирский/пригородный).
