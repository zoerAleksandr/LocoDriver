## Ограничения админки/сервера (проверено по коду proxy-parser)
- Карусель = `type=update`: ≥1 фича, у КАЖДОЙ обязательны картинка, название, описание. Порядок = порядок строк формы.
- Картинки: PNG / JPEG / WEBP, ≤ 2 МБ на файл. SVG и GIF отклоняются. Анимация не воспроизводится (Coil без `coil-gif`) — только статичный кадр.
- Описание ≤ 110 знаков (на крупном шрифте обрезается).
- Номер: предзаполняется `max(number)+1`; при `once` клиент показывает, если number > lastSeen.

## Что с готовыми кадрами
- `map_main.jpg` — в кадре реальный маршрут и станции; ПДн нет. Годится как есть.
- `track_profile.jpg` — альбомная (1280×576); для карусели обрезан по содержимому: `track_profile_crop.png` (2376×1044, без статус-бара и системных кнопок). В карусели лежит вверху рамки, под ним пустая карточка. Видны «№2104 · 798 м» и ограничение — приемлемо.
- `auto_chip.jpg` — в кадре станции, время и чип «АВТО»; ПДн нет (№ поезда 2104 — тот же, что на других кадрах).
- `plan_card.jpg` — карточка «План прибытия»; `plan_goal.jpg` (шаг 2 «Цель») запасной / для сайта.
- `vu45_blank.jpg` — реальный № локомотива (517) и поезда (2104): при желании заменить на выдуманные.

## Шаги публикации
1. Решить по альбомному кадру профиля.
2. Решить `min_build` и дату новости на сайте.
3. `/admin` → новое сообщение → «Обновление», заполнить, загрузить картинки, `once`, `android`; сохранить НЕактивным, проверить на устройстве, затем включить «Активно».
4. Сайт: ветка `feat/news-train-map-auto` репозитория `locodriver-site` → ревью → merge в main — только по команде.
