# Черновик «Новости при запуске»: карта поезда, «АВТО», зоны без GPS, рефералка

Тексты — из `docs/ONBOARDING_MATERIALS.md` §1. НЕ опубликовано, на прод ничего не заводилось. Ввод вручную в `/admin` → «Новость при запуске» → «Новое сообщение».

## Что умеет админка/сервер (проверено по коду proxy-parser)
- Модели: `announcement` (number unique, title, body, type `news|update`, platform `all|android|ios|pwa`, min_build/max_build, display_mode `once|always`, is_active, картинка для news) и `announcement_feature` (position, title ≤255, description, image_data BYTEA, image_mime).
- Карусель = `type=update`: ≥1 фича, у КАЖДОЙ обязательны картинка, название, описание. Порядок = порядок строк формы.
- Картинки: только PNG / JPEG / WEBP, максимум 2 МБ на файл (`ALLOWED_IMAGE_MIMES`, `MAX_IMAGE_BYTES` в `api/v1/admin.py`). SVG и GIF — отклоняются.
- Номер: поле «Номер рассылки» предзаполняется `max(number)+1` (`get_next_number`); можно править вручную. Клиент показывает, если number > lastSeen (для `once`).
- Анимация: сервер принимает анимированный WebP, но Android-клиент грузит через Coil 2.4.0 `AsyncImage` БЕЗ `coil-gif` — анимация не воспроизведётся (будет статичный первый кадр). Добавлять зависимость нельзя без решения. Поэтому в карусели для фичи 7 — статичный кадр (скриншот экрана «Пригласить друга», `referral.png`), анимированный SVG используется только на сайте.
- Текст описания обрезается на крупном шрифте: держать ≤110 знаков (ниже все проверены).

## Поля формы
| Поле | Значение |
|---|---|
| Номер | авто (`max+1`) — подтвердить перед сохранением |
| Платформа | `android` (функции нет на iOS/PWA) |

| Активно | включить только при публикации |

## Шаги публикации
1. Снять скриншоты, заменить заглушки (сайт — файлы в `locodriver-site/screenshots/`, карусель — загрузка через форму).
2. Решить: номер версии в заголовке, min_build, дата новости на сайте.
3. `/admin` → новое сообщение → тип «Обновление», заполнить таблицу, загрузить картинки, режим `once`, платформа `android`; сохранить НЕактивным, проверить предпросмотр/на тестовом устройстве, затем включить «Активно».
4. Сайт: ветка `feat/news-train-map-auto` репозитория `locodriver-site` → ревью → merge в main (Cloudflare Pages деплоит сам) — только по команде. После выхода обновить выдержку в `index.html` (секция NEWS).
