# ВУ-45 — спецификация инструмента «Справка ВУ-45» (ЭТАП 1, без кода)

## 1. Что такое ВУ-45 (важное уточнение к постановке)

ВУ-45 — НЕ справка о расходе топлива/энергии. Это **справка об обеспечении поезда тормозами и исправном их
действии**: осмотрщик вагонов выдаёт её машинисту после полного (ПО) / сокращённого (СО) опробования тормозов.
Документ юридический: по нему машинист сравнивает **фактическое и потребное тормозное нажатие** и выбирает скорость.
Два экземпляра под копирку, подлинник у машиниста до конца поездки (сдаётся с скоростемерной лентой, хранится 3 мес.),
копия у вагонника 7 суток. Расход топлива/энергии — другие документы (маршрутный лист, ТУ-152).

Источники: oltep.narod.ru/hepl_torm/11.4/11.4.htm; studfile.net/preview/11603573/page:26/ (лекция «Справка ф. ВУ-45»);
Инструкция ЦТ-ЦВ-ЦЛ-ВНИИЖТ/277 (на неё ссылаются источники; текст не получен). В стороннем приложении
(/Users/zoer/Downloads/atlix-app, com.example.rzd_app 2.2.4; снят только base.apk без split с libapp.so) строк ВУ-45/VU45
нет ни в assets, ни в dex, ни в newtyga.db — реализации для повторения там не найдено (есть таблицы Shifts/AdditionalData:
вес, оси, усл. длина, электроэнергия — без тормозов). В нашем репозитории ВУ-45 не упоминается.

## 2. Реквизиты справки (лицевая сторона)

Время выдачи; серия и номер локомотива; дата; номер поезда; вес брутто Р (т); число осей; номер хвостового вагона;
плотность тормозной магистрали (ТМ) при ПО/СО на II положении РКМ; подписи осмотрщиков и машиниста. Таблица нажатий:
потребное и фактическое расчётное нажатие (тс), потребное и фактическое число ручных тормозных осей.
Графа IV «Дополнительные данные»: К-100/К-75/К-50 (доля композиционных колодок), ЭПТ, ЭПП, П, В-10, РИЦ, ТЦПВ (выход штока
хвостового вагона, мм), ВСТР (вагон встречи), ДПВ (давление ТМ хвостового вагона, атм), плотность ТМ при IV положении
РКМ, время отпуска хвостовых вагонов (>100 осей, мин), вагон с отключённым тормозом, отметки о пробах на перегонах.

## 3. Формулы

Потребное нажатие: **Па = Р · X / 100** (тс), X — на 100 т веса:
гружёный грузовой 33; порожний 55 (350–400 осей — 44; 400–520 осей — 33); пассажирский 60; грузо-пассажирский 44.
Пример: Р = 3040 т, гружёный → Па = 3040·33/100 = **1003,2 тс**.

Потребные ручные оси: **Пр = ⌈Р · k / 100⌉**. Источники расходятся: k = 0,6 (studfile), 0,8 при уклоне 0,010 (narod);
другая версия: 0,4 оси/100 т до уклона 0,006 и +0,1 за каждые 0,001 уклона. Пример (k=0,8): ⌈3040·0,8/100⌉ = ⌈24,32⌉ = **25 осей**.

Фактическое нажатие = Σ по осям (число осей × нажатие на ось по режиму ВР): ВР 483 — порожний 3,5 / средний 7 / груженый 8,5 тс на ось
(упрощённо; реальная справка считает по типам вагонов/колодок, чугун/композит, коэф. пересчёта — таблицы инструкции 277, их нет).
Условие допуска: **Факт ≥ Потребное**; иначе ограничение скорости по инструкции 277 (таблицы нет).
Контроль в пути: плотность ТМ изменилась > 20 % от записанной → СО.

## 4. Что есть у нас в маршруте и чего не хватает

Есть (Train): `weight` (строка, т), `axle` (строка, оси), `conditionalLength`, `number`; локомотив: серия/номер; время работы.
Нет: гружёный/порожний, режим ВР, состав по осям (груз/порожн), доля композита, ручные оси факт, плотность ТМ, номер хвостового вагона,
ТЦПВ/ДПВ, ЭПТ, таблицы инструкции 277. Расход/нормы в расчёт ВУ-45 не входят.

## 5. Предлагаемая спецификация (минимальная, честная — «калькулятор + бланк»)

**Назначение**: помощник машиниста — рассчитать потребное нажатие и ручные оси, сверить с фактом, вести черновик справки. Не заменяет
официальную справку вагонника; предупреждение в UI.

**Вход**: вес Р (авто из выбранного поезда маршрута, `Train.weight`), оси (авто из `Train.axle`), тип поезда (грузовой гружёный / порожний /
пассажирский / груз-пасс), фактическое нажатие (вводится из справки вагонника, тс), факт ручных осей, уклон (для Пр), плотность ТМ, номер
хвостового вагона, время выдачи, флаги К-100/75/50, ЭПТ, В-10 — необязательные поля для черновика.

**Выход**: Па (тс), Пр (оси), запас/недостаток = Факт − Па (тс и %), вердикт «норма / недостаточно — ограничение скорости по инструкции».
Округление: Па — 1 знак, Пр — вверх до целого.

**UI**: экран «ВУ-45» в стиле инструментальных экранов (Settings unified): карточка «Поезд» (выбор из текущего маршрута или ручной ввод),
карточка «Расчёт» (крупные mono-числа Па / Пр), карточка «Факт» (ввод + индикатор запаса зелёный/красный), сворачиваемая «Дополнительные данные».
Пересчёт — мгновенно при вводе, без кнопки.

**Место**: главный экран, блок «ИНСТРУМЕНТЫ» (SCREEN_SPECS §4 п.8; сейчас Календарь, Карта, Статистика, PDF, Поиск) — новая карточка «ВУ-45»
после «Статистика» (до «PDF»). Нужна иконка ic_card_*.

**Хранение**: локально, привязка к `trainId` (черновик ВУ-45 на поезд) — новая таблица SQLDelight (миграция БД!) либо SharedPreferences для
MVP. **Сервер/JSON не меняется**, в SyncData не попадает (иначе — отдельное согласование контракта). Расчётная логика — чистая функция в
`domain` (commonMain), тестируемая.
