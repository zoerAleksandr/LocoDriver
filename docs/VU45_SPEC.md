# ВУ-45 — инструмент «Справка ВУ-45» (спецификация, реализовано на Android)

Статус: **реализуемо и реализовано** (ветка `feature/vu45`). Поведение экрана — `SCREEN_SPECS.md` §26; здесь — предметная часть:
формулы, таблицы, примеры, источники, оговорки.

## 1. Что такое ВУ-45

Справка об обеспечении поезда тормозами и исправном их действии (не расход топлива/энергии). Осмотрщик вагонов выдаёт её машинисту
ведущего локомотива после полного опробования тормозов (п. 9.3.3 Правил ТО тормозного оборудования; форма - прил. 1 Правил ТО тормозного оборудования, заполнение - Инструкция 808-2022 ПКБ ЦВ, прил. М). Машинист по ней сверяет требуемое и фактическое
нажатие колодок и выбирает скорость. В справке: время выдачи, серия/номер локомотива, дата, номер поезда, вес, всего осей, **требуемое
нажатие колодок, ручные тормоза в осях (потребные/наличие)**, таблица «нажатие на ось × число осей × нажатие колодок» (значения на ось
в бланке по образцу 808-2022, прил. М: 1,25 / 3 / 3,5 / 4,5 / 5 / 5,5 / 6 / 6,5 / 7 / 7,5 / 8 / 8,5 / 9 / 9,5 / 10 / 11 / 11,5 / 12 / 12,5 / 13 / 14 / 15 / 16 / 18 / 19 / 20 / 21 тс), плотность тормозной сети, хвостовой вагон,
доля композиционных колодок (К-75 / К-100), выход штока хвостового вагона, давление в ТМ хвоста и др.

## 3. Формулы

Обозначения: `Qс` — вес состава (тс), `Qл` — учётный вес локомотива (если учитывается), `Q = Qс + Qл`, `N` — норма табл. 1 прил. 2 (тс на 100 тс).

1. **Потребное нажатие** `Па = N × Q / 100` (тс, в пересчёте на чугунные колодки). Для **грузовых** поездов вес и нажатие локомотива не
   учитываются (п. 6.4); для пассажирских/грузопассажирских — учитываются (данные владельца инфраструктуры, п. 6.3 прил. 2; справочник серий - по прежней Инструкции 277).
2. **Фактическое нажатие** `Факт = Σ (нажатие на ось_i × число осей_i) + нажатие локомотива` (табл. 3 прил. 2 — вагоны, п. 6.3 — локомотивы).
   `Факт/100 = Факт × 100 / Q`. **Достаточно**, если `Факт ≥ Па`.
3. **Допускаемая скорость:**
   - `Факт/100 ≥ N` → скорость табл. 1 прил. 2: числитель — спуск до 0,010 включительно, знаменатель — круче 0,010 до 0,015 (для строк 15.3-15.6 до 0,012);
     «−» — норм нет, скорость устанавливает владелец инфраструктуры. Значение в скобках — автоблокировка с 3-значной сигнализацией, зелёный огонь
     АЛСН, спуск не круче 0,010 (п. 3.1).
   - `Факт/100 < N`, но `≥ минимума табл. 2 прил. 2` → **п. 4.4**: скорость табл. 1 прил. 2 (без скобок) уменьшается на **2 км/ч** за каждую недостающую
     тонну (грузовые, рефрижераторные, хозяйственные); для пассажирских, грузопассажирских и рефрижераторных >90 км/ч — на **1 км/ч** при
     спуске до 0,006 и **2 км/ч** при спуске круче 0,006 до 0,015; результат — вниз до кратного 5. Применимо только в случаях п. 4.2-4.3
     (отказ автотормозов в пути, особые составы). *Недостающие тонны берутся с округлением вверх — решение реализации (в тексте Норм не
     уточнено), безопасная сторона.*
   - `Факт/100 <` минимума табл. 2 прил. 2 → скорость по таблицам не определяется (п. 5.1: устанавливает владелец инфраструктуры, на 20 % ниже номограмм).
   - **П. 31:** груженый грузовой поезд с вагонами с нагрузкой от колёсной пары > 21 тс, все автотормоза включены, ВР на среднем режиме,
     композит: **К-75** (≥ 75 % вагонов) и нажатие `< 33`, но `≥ 31` → до 80 км/ч; **К-100** и `< 31`, но `≥ 30` → до 80 км/ч.
4. **Ручные тормоза** (п. 7.2, табл. 4 прил. 2; грузовые, рефрижераторные, хозяйственные, грузопассажирские, почтово-багажные): потребно
   `⌈ Qс × k / 100 ⌉` осей, где `k` — норма на 100 тс. **Единое наименьшее k = 0,6** (в пределах двух и более дорог) — значение по умолчанию.
   По табл. 4 прил. 2 (уклон → оси на 100 тс): до 0,006 → 0,4; 0,008 → 0,6; 0,010 → 0,8; 0,012 → 1,0; 0,014 → 1,2; 0,016 → 1,4; 0,018 → 1,6;
   0,020 → 1,8 (круче — только башмаки). По умолчанию режим «Авто (по уклону)»: `k = max(0,6; табл. 4 прил. 2 для выбранной ступени уклона)` (ступени 0,006…0,020; для диапазонов берётся верхняя граница — безопасная сторона); пользователь может переопределить `k` вручную (0,4…1,8) — значение запоминается (SharedPreferences) и от уклона не зависит; возврат на «Авто» снова следует за уклоном. Тот же выбор уклона задаёт класс для скоростей табл. 1/2 (≤0,010 / круче 0,010 до 0,015; круче 0,015 норм нет). Для пассажирского поезда
   ручные тормоза приводятся в действие у **всех** вагонов — не нормируются. *Округление вверх — решение реализации.*
5. **Расчёт без подсчёта (п. 6.6):** при 100 % исправных тормозов потребное нажатие принимается 60 тс/100 тс для электропоездов, дизель-поездов
   ДР1/Д, АЧ2, пассажирских поездов с пассажирскими локомотивами любых серий и локомотивами ВЛ80, ВЛ10, ВЛ10У, ВЛ11, ВЛ11М, ВЛ65, Э5К, 2ЭС4К и цельнометаллическими
   составами (до 120 км/ч); 33 тс — сплотки метро (до 75 км/ч). В этом случае в справке таблица не заполняется. Экран всегда считает по таблицам.

## 5. Примеры расчёта

1. Груженый грузовой, Q = 3040 тс, 128 осей композит груженый (8,5): `Па = 33×3040/100 = 1003,2 тс`; `Факт = 128×8,5 = 1088 тс` (35,79 на 100 тс) → достаточно,
   80 км/ч (90 при автоблокировке на спуске ≤0,010); ручных осей `⌈3040×0,6/100⌉ = ⌈18,24⌉ = 19`.
2. Те же 128 осей, чугун груженый (7,0): `Факт = 896` (29,47 на 100 тс) → не хватает 107,2 тс; недостаёт `33−29,47 = 3,53` → 4 т → `80 − 2×4 = 72 → 70 км/ч`.
3. 100 осей чугун: 700 тс = 23 тс на 100 < 28 → скорость по таблицам не определяется.
4. Пассажирский до 120, состав 800 тс (64 оси × 10,0) + локомотив 184 тс (8 осей × 14,0): `Q = 984`, `Па = 60×984/100 = 590,4`, `Факт = 640+112 = 752` → достаточно, 120 км/ч.
5. П. 31: 1000 тс, нажатие 31,5 на 100 тс, К-75 → 80 км/ч; 30,5 при К-75 → п. 4.4: 3 т → 74 → 70; 30,5 при К-100 → 80.

## Нормы II и IV для показа
Норма IV считается из нормы II: плотность в IV положении (перекрыша с питанием) «не должна отличаться от плотности при поездном положении ... более чем на 10 % в сторону уменьшения» (Правила, Прил. 2 п. 9.3.3; 808-2022 прил. М, текст порядка заполнения), т.е. время IV >= 0,9 x время II. Цитата 808-2022: «Плотность тормозной сети не должна отличаться от плотности при поездном положении ручки крана машиниста более чем на 10% в сторону уменьшения». Решение владельца: порог IV округляется до ЦЕЛОГО в БОЛЬШУЮ сторону (`BrakeDensity.normIvSeconds`, `ceil(0,9 x II - 1e-9)`, безопасная сторона): II = 69 -> 62,1 -> «не менее 63 сек»; II = 70 -> 63 (0,9 x 70 = 63,00000000000001 не даёт 64); II с поправкой -10 % при 5,3-5,6 (62,1) -> 56. Тот же порог (0,9 от замеренного II, целое вверх) используется при оценке замера IV и в тексте «Допуск: не менее N с». Норма II показывается как раньше («не менее», вверх до 0,1 с, `formatNormSeconds`).

## Учёт локомотива (Правила ТО тормозного оборудования)
Цитаты: п. 6.4 прил. 2 - «При подсчете обеспечения тормозами грузовых поездов вес локомотива и его тормозное нажатие не учитываются.»; п. 8.2 основного текста - владелец инфраструктуры утверждает приложения к Нормам с данными «расчетные нажатия для вагонов, курсирующих во внутригосударственном сообщении, локомотивов и мотор-вагонного подвижного состава, а также учетный вес локомотивов и мотор-вагонного подвижного состава, число его тормозных осей»; п. 6.5 прил. 2 - для одиночного локомотива с вагонами служебно-технического назначения нажатие считается с учётом веса и тормозных средств локомотива. Явного утверждения «в пассажирских поездах локомотив учитывается» в Правилах нет (исключение сформулировано только для грузовых), поэтому автовключение для пассажирских и грузопассажирских выведено из п. 6.3 прил. 2, п. 8.2 и прежней Инструкции 277 (п. 6.3) и помечено как выводное.

## Расчёт граф 3-6 оборота при изменении состава
`TurnaroundComposition.compute(вход лицевой, новый вес, новые оси, строки изменений)`: потребное = ceil(N × Q / 100) (п. 8 прил. М 808-2022), Q = новый вес (вводит машинист) + учитываемый локомотив; N - по категории (для порожних `BrakeNorms.categoryForAxles`: до 350 осей - 55, 350-400 включительно - 44, более 400 до 520 - 33; табл. 1 прил. 2 Правил); ручные оси по табл. 4 прил. 2 (не менее 0,6 на 100 тс, п. 7.2) на новый вес. Фактическое считается по осям (табл. 3 прил. 2: нажатие на ось × число осей): фактическое лицевой (+ локомотив) + Σ прицеплено (оси × нажатие) − Σ отцеплено (оси × нажатие); новое число осей = оси лицевой ± оси строк. Строки изменений хранятся в записи оборота (`TurnaroundEntry.changes: List<WagonChange>`, значение по умолчанию - пусто; старые записи читаются как раньше, формат контракта не менялся: данные справки - непрозрачный JSON). Поля «Всего осей», потребное и фактическое заполняются расчётом, ручная правка сохраняется (`autoFill`; признак - отличие от расчёта). Без строк фактическое вводится вручную. Предупреждения без блокировки: нажатия нет на лицевой, отцеплено больше, чем есть. Тесты: `TurnaroundCompositionTest` (отцепили, прицепили, смешанно, несколько нажатий, отцепка больше доступного, пустые строки, ручная правка, чтение старых записей). Допущение: изменение состава описывается строками «оси × нажатие на ось»; вес вводится отдельно.

## Данные локомотива в справочнике серий пользователя
Вес, число осей, нажатие на ось, объём ГР и число секций хранятся в записи серии пользователя (`LocomotiveSeries`: `weightT, axleCount, axleLoadTf, brakeVolumeL, sectionCount`; Settings.db миграция 26, сервер 056, синхронизируются) и редактируются в Настройки -> Локомотив -> серия -> «ДАННЫЕ ЛОКОМОТИВА».

**Что предзаполняется** (`LocoSeriesDefaults.forSeries`, правило достоверности - только подтверждённое документами или указанное владельцем): вес, оси и нажатие - серии `BrakeLocoCatalog` (табл. 4-5 Инструкции 277, проект прил. 2), КРОМЕ веса 2ЭС4К, 3ЭС4К, 3ЭС5К, 2ЭС6: он справочный (открытые данные производителя) и в справочник пользователя НЕ предзаполняется (в справке ВУ-45 подсказка из каталога остаётся с пометкой источника); оси этих ЭС предзаполняются (8 у двухсекционных, 12 у трёхсекционных - открытая информация, подтверждено владельцем); нажатие 14,0 у этих ЭС и объём ГР 2000 л (2ЭС4К, 2ЭС5К, 2ЭС6) / 3000 л (3ЭС4К, 3ЭС5К) - по указанию владельца (2ЭС5К: вес 192 т и 8 осей - по проекту). Объём ГР остальных серий - только точное значение из примеров групп (файл 1 / Инструкция 277): ВЛ23 1000, ТЭМ1/ТЭМ2/ТЭМ2У/ЧМЭ3 1000, ТЭП60 1030, ТЭП70/75/80 1060, ВЛ65 и ЭП1 1020, ЧС6/7/8/200 1010, ЭП10, ЭП2К, ЧС2К, ТЭП70БС/У, ТЭМ21 1000, ТЭМ7/7А 1020, ВЛ8/ВЛ8М 1440, ВЛ10У и ВЛ11 1500, ВЛ80 (все индексы), ВЛ82, ВЛ82М 1800, ВЛ11М, 2ТЭ116, ТГ102, 2ТЭ70 2000, ВЛ85 2100, ВЛ10К/ВЛ10УК 2400, ТЭ3/ТЭ7 2160, ВЛ15, 2ТЭ10У, 2ТЭ10УТ 2500, 2ТЭ70У 2510 и др. **Не предзаполняется объём ГР:** выведенный по допущениям (2ТЭП60, 2М62, 2М62У, 3ТЭ10М, 3М62У, 4ТЭ10С - по примечанию 4; ЧС1-ЧС4(Т), ЧС3 - нижняя граница ниже таблицы; ЧМЭ3Т/Э, ТЭМ2А/УМ - по семейству), диапазоны (ВЛ60, 2ТЭ10Л/В/М, 2ТЭ121, ЭП1М, ТЭП10, ТЭ10, М62), ВЛ10 (зависит от номера) и серии без данных (ТЭМ16-18, ВЛ11К, 2ТЭ25К и др. - см. «Пробелы справочника локомотивов»).
**Секции:** первая цифра названия, если оно начинается с цифры (2ЭС6 -> 2, 3ЭС4К -> 3, 4ТЭ10С -> 4, 2ТЭ10У -> 2), иначе 1 (ЭП1М, ВЛ80, ВЛ10, ЧС7, ТЭМ2, ЧМЭ3, ЭП2К - цифра внутри названия не число секций). В форме «Локомотив» при выборе серии секций становится столько.

**Подстановка в справку.** Приоритет по каждому полю: запись справочника серий пользователя -> каталог -> пусто. Объём ГР подставляется в «Свой объём ГР» (группа - по прим. 3 табл. 4 п. 9.3.3), пока группа не выбрана вручную. **Запись обратно:** изменённые в справке вес, оси, нажатие, свой объём ГР через 0,8 с перезаписываются в записи серии пользователя (записи нет - создаётся), чтобы следующая справка подставила уже их.
