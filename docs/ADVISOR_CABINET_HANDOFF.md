## Что хочет пользователь
1. В кабинете (/admin/advisor) — **карта**; на ней линиями выделены поездки пользователей по участкам.
2. Нажатие на линию — переход в участок: **наложенные друг на друга (усреднённые) сохранённые профили высот** и **список поездок**, сформировавших профиль.
3. Возможность **исключить любую поездку** из расчёта усреднённого профиля.
4. Возможность **ручного редактирования** профиля.
5. Взять **готовые профили пути из приложения «Атлікс/Atlix» на Samsung** (посмотреть, как они скачиваются, и скачать для наших участков) и использовать как профили участков. ВНИМАНИЕ: прежде чем копировать данные стороннего приложения, выяснить правовую сторону (лицензия/условия, право использования) и согласовать с пользователем; технически — анализ трафика/хранилища на его собственном устройстве.

## Вопросы, которые надо решить в начале
- Откуда берутся «поездки пользователей по участкам» на карте: из вкладов высот (обезличены: ось+км, без времени) или из треков (есть точки, но под согласием №1 и зашифрованы)? Требования приватности: в кабинете не показывать user_id/время/точные координаты без отдельного согласия.
- Модель данных: поездка → вклад (фрагменты по оси) → усреднение (медиана/взвешенное по точности) → профиль участка; флаг «исключена» на вкладе/поездке; версионирование ручных правок.
- Профили из Atlix: формат, способ загрузки, юридическая сторона; сопоставление с нашими участками (axisHash/км).
- Кто имеет доступ в кабинет (админ), аудит правок.
