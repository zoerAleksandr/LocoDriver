# Справочник кодов начислений и удержаний

Источник: все 14 фотографий IMG_0329.HEIC–IMG_0342.HEIC от пользователя.
IMG_0329.HEIC–IMG_0335.HEIC содержат памятку и примеры расчётных листков, IMG_0336.HEIC–IMG_0342.HEIC — табличный справочник. Полный OCR всех страниц сохранён в raw_ocr_transcript.md; подтверждённые рабочие коды находятся в PayrollPaymentCatalog.kt.

## Канонический каталог для поиска

`payroll_codes_verified.csv` — полный построчно проверенный каталог из
`IMG_0336.HEIC`–`IMG_0342.HEIC`. Он является исходником для будущего поиска по
кодам выплат и удержаний. В нём 285 строк и следующие поля:

- `source` — номер исходной фотографии;
- `type` — `ACCRUAL` (начисление) или `DEDUCTION` (удержание);
- `code` — код из справочника, латинские буквы и цифры;
- `short_name` — служебное название из справочника;
- `description` — полная расшифровка;
- `status` — результат ручной проверки по фотографии.

`payroll_codes_ocr.csv` оставлен как исходный результат OCR и не должен
использоваться для поиска или показываться пользователю.

### Известный конфликт источника

Код `035L` напечатан на двух фотографиях с разными значениями:

- `IMG_0339.HEIC` — `ОплВыхДнСверНорПроизКоман`, оплата выходного дня сверх
  нормы в период производственной командировки;
- `IMG_0340.HEIC` — `ОплВыхДнейСверхНорВрМтЛБ`, оплата выходного дня сверх
  нормы по маршруту машиниста.

Обе строки сохранены намеренно вместе с полем `source`. До получения более
точного справочника поисковый интерфейс должен показывать обе расшифровки и
предупреждать о неоднозначности.

## Статусы

- CONFIRMED — код и строка визуально сверены.
- OCR_NEEDS_REVIEW — результат автоматического локального распознавания; возможны ошибки 0/O, 1/I/L, латиница/кириллица и смещение соседней строки.
- Пустое или неполное описание не заменяется догадкой.

payroll_codes_ocr.csv хранит 231 строку данных: исходные OCR-строки и вручную
подтверждённые уточнения пользователя. Это архивный справочник, он не участвует
в расчёте зарплаты и не меняет БД или API.
