## 1. Сервер (первым) — варианты маршрута
`POST /v1/service_phase/route/length`: новый необязательный параметр `alternatives: int` (по умолчанию 1,
максимум 3). Если >1 и промежуточных станций нет — ответ дополнительно содержит `routes[]`:
`{id, lengthKm, geometry (при withGeometry), viaStations: [{name, km, osmId?}]}`; первый — кратчайший и
дублируется в прежних полях ответа. Вариант отличается от найденных не менее чем на 15% длины своей линии;
ищем k альтернатив штрафом на рёбра уже найденных путей (сохраняя правила одного непрерывного пути, разворота
и станционных путей из PR #130/#131/#134). Лимит 200/час считать по запросу, а не по варианту. Тесты на
Лужская — СПбСМ (вдоль залива ≈142,5 км и через Гатчину), Луга — Лужская (один вариант). Доложить: PR, формат
ответа, время ответа (желательно < 3 с).
