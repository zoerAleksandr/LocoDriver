# Диалоговые окна — стандарт (хендофф для Claude Code)

Два платформенных стандарта диалогов. Оба — **центрированные**, поверх затемнения, **только для короткого подтверждения или деструктивного действия** (≤ 2 кнопки, без полей ввода). Всё, что требует ввода/выбора/формы — это нижняя шторка (bottom sheet), **не** диалог.

Затемнение (scrim) для всех диалогов и шторок: `rgba(20, 18, 14, 0.42)` на весь экран.

> **Реализация на Android (Compose):** используем общий компонент
> `com.z_company.route.component.AppAlertDialog` (см. `AppAlertDialog.kt`).
> Он инкапсулирует контейнер (radius 28, surface, тень), типографику и
> порядок/цвета кнопок. Не собирать `androidx…AlertDialog` вручную в экранах.

---

## 1. iOS · Alert

Компонент-референс: `RouteDeleteAlert` (`ios-screens.jsx`). Карточка фиксированной ширины, заголовок и текст **по центру**, кнопки в ряд с разделителями.

### Контейнер
| Параметр | Значение |
|---|---|
| Ширина | `270px` (фиксированная) |
| Радиус | `18px` |
| Фон | `surface` + `backdrop-filter: blur(20px)` |
| Тень | `0 24px 64px rgba(0,0,0,0.34)` |
| overflow | `hidden` |
| Паддинг блока текста | `20px 18px 16px`, `text-align: center` |

### Типографика
| Элемент | Стиль |
|---|---|
| Заголовок | Inter **17 / 700**, цвет `text` |
| Текст | Inter **13 / 400**, `line-height: 1.35`, цвет `textMuted`, `margin-top: 4px` |

### Кнопки
- Ряд `display:flex`, каждая кнопка `flex:1`, `padding: 13px 0`, Inter **16**, фон прозрачный.
- Между текстом и кнопками — горизонтальный разделитель `1px` цвета `border`.
- Между кнопками — вертикальный разделитель `1px` цвета `border`.
- Порядок: **«Отмена» слева** (`accent`, weight **500**), **действие справа** (деструктивное — `danger`, weight **700**).

## 2. Android · AlertDialog (Material 3)

Компонент-референс: `ARouteDeleteDialog` (`android-screens.jsx`). Заголовок и текст **по левому краю**, текстовые кнопки **справа**.

### Контейнер
| Параметр | Значение |
|---|---|
| Ширина | `max-width: 312px` (`width: 100%`) |
| Радиус | `28px` |
| Фон | `surface` |
| Тень | `0 24px 64px rgba(0,0,0,0.34)` |
| Паддинг | `24px` со всех сторон |

### Типографика
| Элемент | Стиль |
|---|---|
| Заголовок | Inter **22 / 600**, цвет `text`, `margin-bottom: 14px` |
| Текст | Inter **14 / 400**, `line-height: 1.45`, цвет `textMuted` |

### Кнопки
- Контейнер `display:flex`, `justify-content:flex-end`, `gap:8px`, `margin-top:24px`.
- Каждая кнопка: `padding: 10px 16px`, `border-radius: 20px`, фон прозрачный, Inter **14**.
- Обе прижаты вправо: **«Отмена»** (`accent`, weight **600**) слева от основного действия, **деструктивное** (`danger`, weight **700**) справа.

## 3. Токены цвета

Кнопки диалогов **всегда текстовые** (без заливки). Обычное действие — `accent`, деструктивное — `danger`.

| Токен | Light | Dark | Material-слот в теме приложения |
|---|---|---|---|
| `accent` | `#00A0F5` | `#33BFFF` | `colorScheme.tertiary` |
| `danger` | `#FF4053` | `#FF6575` | `colorScheme.error` |
| `text` | `#0A0E14` | `#F5F5F5` | `colorScheme.primary` |
| `textMuted` | `rgba(10,14,20,0.55)` | `rgba(245,245,245,0.60)` | `colorScheme.onSurfaceVariant` |
| `surface` | `#FFFFFF` | `#2A2B2D` | `colorScheme.surface` |
| `border` | `rgba(10,14,20,0.06)` | `rgba(255,255,255,0.08)` | `colorScheme.outlineVariant` |

Шрифты: `Inter` (основной), `JetBrains Mono` (числа/технические подписи — в диалогах не используется).

---

## 4. Правила

- **Диалог или шторка?** Диалог — только короткое подтверждение / деструктивное действие (2 кнопки, без ввода). Любой ввод, выбор или форма — нижняя шторка (iOS радиус `24px` сверху, Android `28px`, grabber-полоска сверху, то же затемнение).
- **Порядок кнопок.** iOS: «Отмена» слева, действие справа. Android: обе прижаты вправо, «Отмена» слева от основного действия.
- **Деструктивная кнопка** всегда `danger` и жирнее (**700**).
- **Если красная кнопка по смыслу не нужна** (не деструктивное действие) — основную кнопку делаем `accent` (синей), вторую — серой (`textMuted`). Красный (`danger`) не используем.
- **Затемнение** одинаковое везде: `rgba(20,18,14,0.42)`, кликом по нему диалог закрывается (= «Отмена»).
- **zIndex** диалога — `80` (выше шторок `70`).
