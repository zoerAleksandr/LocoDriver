# Handoff: Быстрый просмотр маршрута — Android (Material 3)

Дополнение к основному пакету (`README.md`, `tokens.js`). Описывает **новый экран**: быстрый просмотр маршрута по долгому нажатию на строку в списке.

Референс в макете: секция **«Android · Быстрый просмотр маршрута»** в `Машинист - Android (standalone).html` (и в `Машинист - Android.html` проекта). Исходник: `android-route-quick-view.jsx`; данные и переиспользуемые строки — `route-quick-view.jsx`.

---

## 1. Что это и зачем

Пользователь (машинист) в списке маршрутов делает **долгое нажатие** на строке — снизу выезжает **шторка (bottom sheet)** со всей подробной информацией по маршруту, не открывая полный экран редактирования. Это «быстрый взгляд» + набор быстрых действий.

Важно: это **Android-паттерн**. На iOS тот же сценарий реализован как «peek» (размытие фона + плавающий диалог по центру + контекстное меню сбоку). **Не переносите iOS-подачу на Android.** На Android — родная `ModalBottomSheet`, затемнение (scrim) без блюра, действия в нижней панели.

## 2. Триггер

- Долгое нажатие на всю строку маршрута в списке «Все маршруты» (и в любом другом списке маршрутов).
- Использовать `Modifier.combinedClickable(onClick = openRoute, onLongClick = openQuickView)` — обычный tap по-прежнему открывает полноэкранный `RouteScreen`, long-press открывает шторку. Не заменять tap.
- Тактильный отклик в момент срабатывания:
  `LocalHapticFeedback.current.performHapticFeedback(HapticFeedbackType.LongPress)`.
- `indication` — стандартный ripple строки.

## 3. Контейнер шторки

- `ModalBottomSheet` (androidx.compose.material3).
- `sheetState = rememberModalBottomSheetState(skipPartiallyExpanded = true)` — открывается сразу раскрытой, без half-expanded.
- Высота: раскрытая шторка занимает ~90–92% высоты экрана (в макете верх шторки отстоит ~30px от верха рабочей области). Не делать full-screen — сверху должна оставаться полоска scrim, чтобы читалось «это оверлей поверх списка».
- `shape = RoundedCornerShape(topStart = 28.dp, topEnd = 28.dp)`.
- `dragHandle = { BottomSheetDefaults.DragHandle() }` — штатная ручка 32×4 dp, цвет `borderStrong`.
- `containerColor = colorScheme.background` (`bg`), `scrimColor = BottomSheetDefaults.ScrimColor` (штатное затемнение). **Не** добавлять `Modifier.blur()` и **не** масштабировать фон — это iOS.
- Закрытие: свайп вниз, тап по scrim, системная «назад».

## 4. Внутренняя структура (сверху вниз)

```
[drag handle]                       ← штатная ручка
[Шапка — tonal контейнер]           ← фиксированная, не скроллится
[LazyColumn — контент]              ← weight(1f), вертикальный скролл
[Bottom action bar]                 ← фиксированная, не скроллится
```

### 4.1 Шапка (tonal header)
Фон — `accentSoft` (тональный акцентный контейнер), нижняя граница `border`. Внутри:
- строка «Маршрут №147» — метка `textMuted` 13sp + номер mono 19sp/700 `text`;
- направление: «Иланская → Боготол», 17sp/600 `text`, стрелка в `accent`;
- ряд из двух плашек (`surface`, радиус 12dp): **«Время работы»** (значение mono 22sp/800) и **«Отдых»**. Плашка отдыха имеет два режима (см. §5);
- ряд чипов (`surface`, радиус 9dp): **заработок** (иконка ₽ в `accent`) и **статус синхронизации** — «Синхронизирован» (`success` + иконка sync) либо «Не синхронизирован» (`textMuted` + иконка cloud-off).

### 4.2 Контент (скролл, `LazyColumn`)
Каждая секция = mono-подзаголовок (10.5sp, `textMuted`, uppercase, letter-spacing ~1.3, паддинг `16/20/7`) + карточка (`surface`, радиус 14dp, `margin 0 14dp`, внутренние разделители `border`). Порядок:

1. **Время работы** — строки «Явка» и «Сдача»: метка + опциональный тег (mono, `accent` на `accentSoft`) + две плашки дата/время (`bgSubtle`, mono).
2. **Отдых в пункте оборота · {станция}** — только если `rest.mode == "po"`: строки «Короткий отдых» и «Полный отдых» (полный — значение в `accent`); каждая: подпись + «до {дата·время}» + длительность mono 18sp/800.
3. **Локомотивы · N** — по каждому: иконка в тональном боксе (`bgSubtle`/`accent`, 36dp, радиус 10) + название. Показания секций не суммируются: каждая заполненная секция получает собственный блок «Секция N» со счётчиками «принял → сдал» и итогом (рекуперация/экономия — знак «−» и цвет `success`). Для тепловоза основное значение счётчика показывается в литрах, а масса в кг, рассчитанная по коэффициенту этой секции, располагается под плашкой, вне её фона; экипировка выводится в соответствующей секции с объёмом в литрах и/или массой в кг. Опциональный тональный итог (`accentSoft`).
4. **Поезда · N** — по каждому: шапка (иконка + № + плечо) + характеристика (mono, `textMuted`) + вертикальный график станций: рельс с точками (первая/последняя — `accent`), название, бейдж «стоянка · N мин» (цвет по длительности: >30 мин `danger`, >5 мин `warning`, иначе `textMuted`), времена приб/отпр (mono).
5. **Следование пассажиром** — та же карточка поезда с иконкой «пассажир».
6. **Доплатные признаки** — чипы (`surface`, радиус 10, тень sm): иконка в `accent` + подпись. Набор: повышенная длина, повышенная масса, свыше 12 часов, удлинённое плечо (иконки — из набора `icons.jsx`).
7. **Заметки** — карточка (`surface`, радиус 14) с текстом 14sp/`text`, line-height 1.5.

Внизу списка — короткий градиент-затемнение (fade `bg 0 → 0.9`, высота ~20dp) как подсказка прокрутки.

### 4.3 Нижняя панель действий (Material bottom app bar)
Фиксирована под контентом, высота 72dp, фон `surface`, верхняя граница `border`. Совпадает по составу с нижней панелью экрана «Маршрут»:
- **слева** ряд `IconButton` (48dp таргеты, цвет `text`): Открыть (pencil), В избранное (heart), Поделиться (share), Копировать (copy);
- **Синхронизировать** (sync) — показывать **только если `!route.synced`**;
- **справа** (прижата `weight`-спейсером) — **Удалить** (trash) в цвете `colorScheme.error` (`danger`).

## 5. Два режима отдыха

Плашка «Отдых» в шапке и секция §4.2.2 зависят от типа отдыха маршрута:
- **Домашний** (`rest.mode == "home"`): плашка показывает длительность + тип + «до {дата·время}»; отдельной секции «Отдых в ПО» в контенте нет.
- **В пункте оборота** (`rest.mode == "po"`): плашка показывает **короткий** и **полный** отдых (полный — в `accent`); дополнительно рендерится секция «Отдых в пункте оборота · {станция}».

## 6. Действия и переходы

| Действие | Поведение |
|---|---|
| tap по строке (не long-press) | полноэкранный `RouteScreen` (не шторка) |
| Открыть (pencil) | закрыть шторку → `RouteScreen` в режиме редактирования |
| В избранное | тоггл флага, снек-бар подтверждения; иконка отражает состояние |
| Поделиться | системный share-sheet |
| Копировать | дублировать маршрут, снек-бар с «Отменить» |
| Синхронизировать | запустить синхронизацию (виден только для несинхронизированных) |
| Удалить | `AlertDialog` подтверждения (заголовок «Удалить маршрут?», «Отмена» / «Удалить» в `error`) — **не** удалять сразу |

## 7. Токены и типографика

- Всё — из существующей темы: цвета `MaterialTheme.colorScheme`, типографика `MaterialTheme.typography`. Ничего не хардкодить.
- Числовые значения (время, суммы, счётчики, даты) — **моноширинным** шрифтом приложения (в макете JetBrains Mono; в проекте — тот же моно, что используется на остальных экранах).
- Точные размеры/отступы/радиусы — сверять с `route-quick-view.jsx` и `android-route-quick-view.jsx`.

## 8. Доступность

- Каждая `IconButton` — с `contentDescription` (значения в `AQVActionBar`: «Открыть», «В избранное», «Поделиться», «Копировать», «Синхронизировать», «Удалить маршрут»).
- Таргеты действий — не меньше 48dp.
- Шторка перехватывает фокус; системная «назад» и тап по scrim закрывают её.
- Долгое нажатие дублирует то, что доступно и обычным путём (открытие маршрута) — это ускоритель, а не единственный путь.

## 9. Чего НЕ делать

- Не размывать фон и не масштабировать список под шторкой (это iOS-peek).
- Не выносить действия в плавающее контекстное меню сбоку — на Android они в нижней панели.
- Не открывать шторку по обычному tap — только по long-press.
- Не хардкодить цвета/шрифты — брать из темы.
