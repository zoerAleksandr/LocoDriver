# Handoff: Промежуточные станции в плечах обслуживания (Android)

## Обзор
Сейчас у плеча есть только две крайние станции. Добавляем:
1. **Промежуточные станции** — упорядоченный список от отправления к прибытию.
2. **Ручное добавление и редактирование** списка: тап по станции, удаление, перетаскивание, вставка между соседними.
3. **Автоподбор** «Найти автоматически»: сервер по данным OpenStreetMap строит путь между крайними станциями и возвращает станции с координатами и км. Пользователь проверяет и подтверждает. **Без подтверждения ничего не записываем.**
4. **Выбор точки на карте** для одной станции: «Указать на карте» → полноэкранная карта → «Выбрать».

Координаты нужны для будущего автоопределения станции по GPS. В интерфейсе видно только «координаты есть / нет», без чисел.

## Общие правила

**Шрифты** (см. `Правила шрифтов.md`):
- **Mono** (JetBrains Mono): км, ЕСР, заголовки групп (UPPERCASE), подстрока строки станции, атрибуция.
- **Sans** (Inter): названия станций, заголовки, кнопки, пояснения.

**Цвета** — только из `tokens.js`:
- `accent` — действия;
- `warning` — «нет координат», расхождение длины;
- `success` — «координаты есть», выполненный шаг;
- `danger` — **только** удаление.

Полупрозрачные подложки считаются из существующих токенов через `hexToRgba(color, a)` и **не являются новыми токенами**:

| Где | Формула |
|---|---|
| плашки | `warning` / `accent` @ 12% |
| квадрат-иконка | цвет @ 14% |
| кружок выполненного шага | `success` @ 15% |
| ореол точки на карте | `accent` @ 20% |
| трек спиннера | цвет @ 22% |
| обводка «+» вставки | `accent` @ 50% |

**Кнопки** (`PstBtn`): высота 44, радиус = h/2 (пилюля), sans 15/600, gap иконка–текст 8, padding 0 20 (у text — 0 12).

| Вариант | Фон / цвет текста |
|---|---|
| filled | `accent` / `accentInk` |
| tonal | `accentSoft` / `accent` |
| outlined | прозрачный, обводка 1px `borderStrong` / `text` |
| text | прозрачный / `accent` |
| cta | `cta` / `ctaInk`, h 52 |
| danger | прозрачный / `danger` |

Disabled (кроме text): фон `bgSubtle`, текст `textFaint`, у outlined обводка `border`.

**Шторка** (`PstSheet`):
- Высота: редактор 94%, автоподбор 92%, шторка станции — по содержимому.
- Фон `bg`, верхние углы 28, тень `M.shadow.sheet`.
- Грэббер 36×4, радиус 3, `borderStrong`, отступ сверху 8.
- Шапка: padding 8 12 6 20. Заголовок sans 22/500, letter-spacing −0.2. Подзаголовок sans 13 `textMuted`, отступ 2.
- Кнопка ✕: 40×40, иконка 22, `textMuted`.
- Тело прокручивается, padding 6 16 24.
- Футер закреплён: padding 10 16 14, сверху линия 1px `border`, фон `bg`, gap 8.
- Закрытие ✕, свайп вниз или системный «назад» = отмена без сохранения.

**Поле** (`PstField`):
- Мин. высота 56, padding 8 14, радиус 16, фон `surface`, тень `sm`, рамка 2px прозрачная. В фокусе рамка 2px `accent` и без тени.
- Лейбл sans 12 `textMuted`; в фокусе — `accent`.
- Значение sans 16/600, letter-spacing −0.2, межстрочный 1.25, переносится по словам.
- Плейсхолдер sans 16/400 `textFaint`.
- Leading-иконка `IcMapPin` 18: `accent`, у пустого поля — `textFaint`. Gap 10.
- Суффикс («км») sans 13 `textMuted`.

Сверху вниз:
1. **Поля.** Колонка с gap 8:
   - «От станции» и «До станции» — `PstField` с `IcMapPin`, автодополнение как сейчас;
   - ряд из двух полей по flex 1, gap 8: «Расстояние, км» и «Доплата за пробег, ₽/км».

   Существующие поля не меняются, визуально их не трогаем.
2. **Только для нового плеча:**

   Логика: список разворачивается, км пересчитываются как «расстояние − км»; станции без км остаются без км.
3. **`GroupHead` «ПРОМЕЖУТОЧНЫЕ СТАНЦИИ · N»**, отступ сверху 22. Справа text-кнопка h32, sans 14/600 `accent`: «Изменить», в режиме правки «Готово». Если список пуст, кнопки нет.
4. **Блок станций:**
   - **Пусто (`02`, `03`).** `MCard`, padding 16:
     - пояснение sans 14, межстрочный 1.45, `textMuted`;
     - колонка кнопок, отступ 14, gap 8: filled «Найти автоматически» (`IcSearch` 18, на всю ширину) и outlined «Добавить вручную» (`IcPlus` 18).
     - Если пусто «От станции» или «До станции» — filled-кнопка disabled, под ней подпись sans 12 `textMuted` по центру, отступ 10.
   - **Заполнено (`04`–`06`).** `MCard` со схемой участка (см. «Схема участка» ниже). Под картой ряд кнопок, отступ 10, gap 8:
     - tonal «Найти автоматически» (`IcSearch` 17, flex, padding 0 12);
     - tonal «Станция» (`IcPlus` 17, padding 0 16) — добавляет в конец; если у новой станции указан км, она встаёт по км.
   - **Длинный список не сворачивается:** виден целиком, прокручивается вместе со шторкой (`05`, `06`). Для 30–50 станций — `LazyColumn` на всю шторку; поля и блок станций — `item {}`.
   - **Режим «Изменить» (`07`).** Под картой только `SectionNote` с подсказкой, кнопок нет (детали — в «Режим правки»).
5. **«Удалить плечо»** — только при редактировании и не в режиме правки. Кнопка danger h44 с `IcTrash` 16, по центру, отступ сверху 18. Открывает диалог.
6. **Футер:** cta h52 на всю ширину — «Добавить» для нового, «Сохранить» для существующего.

**После автоподбора (`08`):**
- добавленные строки подсвечены: фон `accentSoft`, радиус 12; подсветка гаснет через 2 с;
- снекбар (`PstSnackbar`) у низа тела шторки, над футером: отступы слева/справа/снизу 12, радиус 8, фон `cta`, текст `ctaInk` sans 14, межстрочный 1.35, padding 6 6 6 16, мин. высота 48;
- действие «Отменить» sans 14/600. Цвет: в светлой теме `M.dark.accent` #33BFFF, в тёмной `M.light.accentHover` #0091D9 — ради контраста на инверсном фоне;
- «Отменить» полностью откатывает автоподбор, включая добавленные в справочник названия;
- снекбар держится 6 с.

### Схема участка (`PstLine` / `PstStopRow`)
- Внутренний padding карточки 4 8 4 6.
- Колонка линии шириной 32. Линия пунктирная 1.5px `borderStrong` по центру колонки. От первой точки вниз и до последней сверху, концы не выступают.
- **Точки** (по центру строки):

| Тип | Размер | Вид |
|---|---|---|
| крайняя станция | 14 | заливка `text` |
| станция | 12 | фон `surface`, обводка 2px `borderStrong` |
| О.П. | 8 | фон `surface`, обводка 1.5px `textFaint` |

- **Строка:** мин. высота 56 (у О.П. 48), padding 8 4, gap 10. Снизу линия 0.5px `border`, у последней строки нет.
- **Название:**
  - станция: sans 15/600 `text`;
  - О.П.: sans 14/500 `textMuted`;
  - межстрочный 1.25, letter-spacing −0.2, **максимум 2 строки**, потом многоточие. Переносы по дефисам и словам, «Санкт-Петербург-Товарный-Витебский» не ломает строку.
- **Подстрока:** mono 11/500 `textFaint`, части через « · », gap 6, каждая часть не разрывается:
  - «отправление» / «прибытие» — у крайних станций;
  - «станция · ЕСР 030329» — ЕСР только если есть;
  - «О.П.» — ЕСР у О.П. не показываем;
  - «нет координат» — цвет `warning`, только у промежуточных без координат;
  - «уже в списке» — цвет `accent`, только в предпросмотре.
- **Км справа:** mono 13/500 `textMuted`, формат «25,1 км» (одна цифра после запятой, запятая). Нет км — «—» цветом `textFaint`. У отправления «0 км», у прибытия — введённое расстояние целым числом.
- В обычном режиме у промежуточных `IcChevronRight` 14 `textFaint`. У крайних на его месте пустое место 14, и они не нажимаются: правятся в полях сверху.
- **Тап по промежуточной** → шторка станции.

### Режим правки (`07`)
- Справа у промежуточных две кнопки 36×40:
  - ✕ (иконка 18 `textMuted`) — убрать сразу, без диалога, снекбар «Станция убрана» + «Отменить»;
  - ≡ (`PstIcDrag` 20 `textMuted`, при перетаскивании `accent`) — перетаскивание. Long-press по строке тоже поднимает её.
- У крайних станций на месте кнопок пустое место 68.
- **Поднятая строка:** фон `surface`, радиус 12, тень `M.shadow.floating`, смещение +4 по X, масштаб 1.015, линия в её колонке скрыта. Крайние станции перетаскивать нельзя; промежуточные нельзя поставить до отправления или после прибытия.
- **Вставка** (`PstInsertRow`, высота 30) — между каждой парой соседних строк, на линии:
  - кружок 22 с фоном `surface`, обводкой 1.5px `accent` @ 50%, `IcPlus` 12 `accent`;
  - рядом подпись «вставить», sans 12/500 `textFaint`, отступ 10;
  - тап → шторка «Новая станция» с этой позицией. Пока она открыта, кружок залит `accent`, подпись «Вставить станцию сюда» цветом `accent`.
- Км при перестановке не пересчитываются и не сортируют список.
- «Готово» выходит из режима. Изменения попадают в плечо только по «Сохранить».

### 5.3 Предпросмотр · `19`–`22`
Сверху вниз:
1. **Сводка.** Колонка, gap 3, padding 6 4 12.

   - Иконка `IcInfo` 18 цвета плашки.
   - Заголовок sans 14/600 `text`.
   - Текст sans 13, межстрочный 1.45, `text`, прозрачность 80%.

     - **Расхождение длины** (`warning` @ 12%).

     - **Повторный подбор** (`accent`, без заголовка).
       - Поясняет, что уже добавленные станции остаются.
       - Стоит отступом 8 под плашкой длины, если та есть.

5. **Список** `MCard`, отступ 12. Схема участка в режиме выбора.
   - Крайние станции без чекбокса.

     - заблокирован: фон `textFaint`.

   - Тап по строке переключает чекбокс.
   - **«Уже в списке»** (`21`) — совпадение по названию и типу с текущим списком.
     - Чекбокс заблокирован.
     - Станция не дублируется и не удаляется.
     - Если у неё не было координат, км или ЕСР — дополняем из результата.
     - Ручные станции, которых нет в результате, остаются на своих местах.
6. **Футер:**
   - **Чекбокс справочника** (только если N > 0): строка с gap 12, текст sans 14 «Добавить N новых названий в справочник станций».

     - По умолчанию **вкл**.
     - Отдельного шага нет.
   - **Кнопки:** outlined «Отмена» h48 и filled «Добавить N станций» (flex).
     - N — число отмеченных, склонение: «станцию» / «станции» / «станций».

   - **Атрибуция:** «© участники OpenStreetMap», mono 10 `textFaint`, по центру.
     - Обязательна по лицензии ODbL, показывается всегда.
     - Это единственное место с названием сервиса.
7. **«Добавить…»:**
   - станции вставляются по км;
   - шторка закрывается;
   - редактор показывает состояние `08`.

**Порядок вставки:**
- Итоговый список сортируется по км.
- Станции без км стоят сразу после ближайшей предыдущей станции с км (как были).
