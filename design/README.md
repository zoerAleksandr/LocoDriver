# Handoff: «Машинист» — Android-приложение

Пакет для разработчика, реализующего дизайн в реальном кодовом проекте с помощью Claude Code.

---

## 1. Обзор

«Машинист» — мобильное приложение для локомотивных бригад (машинистов и помощников) железной дороги. Оно ведёт учёт рабочих смен («маршрутов»), считает зарплату по тарифам и нормам, ведёт график работы и календарь, показывает статистику переработки и нормы рабочего времени, справочники серий локомотивов и станций.

Этот пакет покрывает **Android-версию** (Material 3). В проекте также есть iOS-версия — те же экраны в iOS-обвязке; здесь она не документируется, но многие экраны используют общие кросс-платформенные компоненты с параметром `platform="android"`.

Язык интерфейса — **русский**. Весь текст в макетах финальный, его нужно перенести как есть.

## 2. О файлах в этом пакете

Файлы в папке — это **дизайн-референсы, сделанные на HTML/React (JSX + Babel в браузере)**. Это прототипы, показывающие желаемый вид и поведение, **а не продакшен-код для копирования напрямую**.

Задача — **воссоздать эти экраны в среде целевого проекта** (Jetpack Compose / Kotlin, React Native, Flutter и т. п.), используя его устоявшиеся паттерны, навигацию и компоненты. Если среды ещё нет — выбрать наиболее подходящий стек под нативное Android-приложение (рекомендуется **Jetpack Compose + Material 3**, так как макеты построены по M3) и реализовать дизайн там.

### Как смотреть макеты
- **`screenshots/`** — PNG-скриншоты (по одному на каждый из 23 экранов, основное светлое состояние). Быстрый обзор без запуска.
- **`Машинист - Android (standalone).html`** — открыть в браузере. Это автономный файл со **всеми** Android-экранами на бесконечном холсте (light + dark). Лучший способ увидеть итог. Требуется интернет (React/Babel/шрифты с CDN).
- **`tokens.js`** — исходная дизайн-система (цвета, типографика, радиусы, тени, спейсинг). Главный источник значений.
- **`src/*.jsx`** — исходники компонентов экранов. Читать для точных размеров/отступов/логики.

## 3. Степень проработки (Fidelity)

**High-fidelity (hi-fi).** Финальные цвета, типографика, отступы, состояния и взаимодействия. UI нужно воссоздавать **пиксель-в-пиксель**, используя M3-компоненты целевого кодстека. Значения брать из `tokens.js` и из исходников экранов.

## 5. Каркас экрана и общие компоненты

Все Android-экраны обёрнуты в устройство-каркас:

- **`ADevice`** (`src/android-screens.jsx`) — рамка телефона 390×844 (высота варьируется), `borderRadius 32`, рамка 6px, тень `0 40px 80px rgba(0,0,0,.22)`. Внутри: статус-бар → контент (`flex:1, overflow:hidden`) → gesture-pill (полоска 120×3 снизу). В реальном приложении рамка устройства **не нужна** — это только для презентации макета; берите внутренний контент.
- **`AStatus`** — статус-бар Android: время «15:13» слева, камера-вырез по центру, иконки сети/батареи справа, высота 36.
- **`MCard`** — карточка: `surface`, `borderRadius 16`, `overflow:hidden`, тень `sm`. Строки внутри разделяются `<div height:1 background:border/>`.
- **`AGroup`** — заголовок группы: mono 11, letterSpacing 1.2, UPPERCASE, `textMuted`, padding `18px 4px 8px`.
- **Bottom sheet** (паттерн `ARouteSheetShell`, `AUnitsSheet`, `ALegendSheet`): затемнение `rgba(20,18,14,0.42)` на весь экран, лист снизу `borderRadius 28px 28px 0 0`, фон `bg`, ручка 32×4 по центру сверху, заголовок 22/600, прокручиваемое тело.
- **AlertDialog** (`ARouteDeleteDialog`): центрированный, `maxWidth 312`, `borderRadius 28`, padding 24, заголовок 22/600, текст 14 `textMuted`, кнопки справа («Отмена» — accent, деструктивная — danger).
- **Bottom App Bar / Navigation Bar**: высота 72–80, `surface`, верхняя граница `border`. Навигация из 5 пунктов: **Главный · Зарплата · (+) · Настройки · Профиль**, активный — accent + тональная подложка `accentSoft`, центральная «+» — pill-FAB `56×32` акцентного цвета.

Иконки — в `src/icons.jsx` (компоненты `Ic*`, напр. `IcLocomotive`, `IcRails`, `IcRuble`, `IcCalendar`, `IcSync`, `IcLogo`). В целевом проекте заменить на эквиваленты из его иконочной системы, сохранив смысл и размер (обычно 22×22 в навбарах, 18–20 в строках).

## 6. Экраны

Полный перечень секций (как на холсте в HTML). Для каждого экрана есть **light** и **dark**, ширина 390. Точные размеры/отступы — в указанном исходнике.

1. **Сплэш** (`splash-screens.jsx`, `AndroidSplash`) — логотип по центру, слоган внизу.
2. **Маршрут** (`android-screens.jsx`, `AndroidScreenRoute`) — карточка смены: номер, плитки «Расчёт»/«Отдых», время работы (Явка/Сдача), группы Локомотивы/Поезда/Пассажиром, заметки. Состояния: `empty` (новый) / `filled`; шторки `calc` (разбивка заработка), `rest` / `rest-home` (отдых, segmented-переключатель «Домашний / В пункте оборота»); диалог удаления `confirm="loco"`; предупреждение `nightWarn` (вторая ночь подряд). Bottom app bar: настройки + обратимые действия (избранное/поделиться/копировать) + удаление справа (danger). **Кнопки «Сохранить» нет — данные сохраняются автоматически.**
3. **Главный** (`android-screens.jsx`, `AndroidScreenTrips`) — large top app bar, hero-метрика месяца «Отработано 205:05» + чип «+30:05 сверх», свайп-карточка (3 страницы: нормы / виды работы / доплатные признаки) с точечным индикатором, «Текущий маршрут» (горизонтальные плитки 150×150: На работе, Локомотив, Поезд, Пассажиром), «Последние маршруты» (строки с иконками-признаками и статусом синхронизации), «Инструменты» (плитки График/Отвлечения/Поиск/PDF). Состояния: `current` / `upcoming` (до явки) / `rest` (отдых в ПО) / `empty`; шторки `legend` (обозначения значков) и `units` (список единиц одного типа).
4. **Все маршруты за месяц** (`all-routes.jsx`, `AndroidScreenAllRoutes`) — top app bar, переключатель месяца «‹ Май ›», assist-chips фильтр/сортировка, карточки маршрутов с плотностью `compact`/`expanded` (разворот — все локомотивы и поезда), шторки `filter`/`sort`, пустой месяц.
5. **Добавление поезда** (`android-add-train.jsx`, `AndroidScreenAddTrain`) — форма; шторки `shoulders` (плечи), `settings` / `settings-expanded`.
6. **Шторка станции** (`station-edit-sheet.jsx`, `StationEditSheetWrap` + `platform="android"`) — режимы `edit` / `new`.
7. **Следование пассажиром** (`pass-screen.jsx`, `AndroidScreenPass`) — флаг `workStart`.
8. **Локомотив** (`locomotive-screens-v2.jsx`, `AndroidScreenLocomotiveV2`) — `traction="diesel"` (тепловоз) / `electric` (электровоз); экипировка свёрнута/развёрнута (`supplyExpanded`); шторки `{kind:'section'|'supply', value}` (коэффициенты секции / экипировки).
9. **Шторка ввода времени** (`time-sheet.jsx`, `SheetWrap` + `platform="android"`) — `kind="arrival"` (приёмка) / `departure` (сдача); пикеры `picker="station"|"series"`; состояния `stationEmpty`, `noSeriesNorm`/`noStationNorm`.
10. **Справочники норм** (`norms-screens.jsx`): `AndroidSeriesList`, `AndroidSeriesEditor`, `AndroidStationsList`, `AndroidStationEditor`.
11. **Настройки** (`settings-screens.jsx`, `AndroidScreenSettings`) — хаб.
12. **Настройки · Основные** (`AndroidScreenSettingsGeneral`).
13. **Настройки · Зарплата** (`salary-settings.jsx`, `AndroidScreenSalarySettings`) — filled-инпуты, bottom sheet даты тарифа (`sheet`).
14. **Календарь** (`calendar-variants-de.jsx`, `CalendarVariantE` + `platform="android"`) — режимы `expanded` (месяц) / `collapsed` (неделя); шторка «Что добавить?» (`initialSheetOpen`); день-выходной (×2 тариф); добавление маршрута (`RouteAddScreen`); отвлечение-диапазон (`AbsenceFlowScreen`, напр. `type="vacation"`).
15. **Мастер «Заполнить месяц»** (`schedule-wizard.jsx`, `ScheduleWizardScreen` + `platform="android"`) — шаг 1 (паттерн 2/2 или свой цикл, редактирование смен, пикер типа дня, подтверждение удаления), шаг 2 (старт + предпросмотр).
16. **Профиль** (`android-profile.jsx`, `AndroidProfile`) — large top app bar, navigation bar, фото/имя из VK ID, email, подписка, синхронизация, выход. `plan="pro"|"free"` (free → апселл в Покупки), `vk` (вход по VK выполнен/нет).

19. **Статистика** (`stats-screens.jsx` + `stats-ui.jsx` + `stats-data.jsx`, фабрика `statsArtboards({platform:'android', dark})`) — Месяц / Год / История, детализация, пустое состояние.
20. **Зарплата** (`salary-screen.jsx`, `AndroidScreenSalary`) — small top app bar, тональный hero «К выдаче», таблицы с фикс. колонками, filled-итог, navigation bar.
21. **Виджеты** (`widgets.jsx`): `WidgetMini` (2×2 — норма за месяц), `WidgetExpanded` (4×4 — норма + маршрут + быстрая запись), `WidgetHome` (на домашнем экране). Единая система: чёрный чип «М», mono-метрика, индикатор нормы.

## 7. Взаимодействия и поведение

- **Темы:** light/dark переключаются по `dark`. Каждый цвет берётся из `t`. Реализовать обе.
- **Bottom sheets:** появляются снизу со скрим-подложкой; внутренний контент скроллится; ручка сверху; закрытие по скриму/свайпу вниз. Триггеры: плитки «Расчёт»/«Отдых», «Все (N)», выбор станции/серии, дата тарифа, «Что добавить?» в календаре, продление подписки, список единиц.
- **Свайп-карточка на Главном:** горизонтальный свайп между 3 страницами метрик; точечный индикатор внизу (активная точка шире, анимация `width .2s`).
- **Горизонтальные ленты:** «Текущий маршрут» и «Инструменты» — горизонтальный скролл со `scroll-snap`.
- **Удаление:** деструктивные действия — цвет `danger`, подтверждение через AlertDialog.
- **Признаки маршрута:** набор иконок (праздничный день, перерыв, повышенная длина/масса, удлинённое плечо, одно лицо, пассажиром, свыше 12 ч, толкач, двойная тяга, сдвоенный) + иконка статуса синхронизации (`success` если синхронизирован, иначе `textFaint`). Легенда — в шторке «Обозначения».
- **Автосохранение:** на экране Маршрут нет кнопки «Сохранить» — изменения применяются сразу.
- **Тач-зоны:** кнопки навбара 48×48, минимальная высота инпута 44 (учтено в токенах).
- **Подписка:** free-план показывает апселл; состояния активна / скоро истечёт (`daysLeft`) / истекла.
- **Авторизация:** табы Вход/Регистрация; вход e-mail+пароль или VK ID; ошибки полей; восстановление пароля по письму (экран «письмо отправлено»).

## 8. Состояние (State)

Ориентировочные состояния, которые нужно завести в реальном приложении:
- **Тема** (light/dark, опц. палитра).
- **Маршрут/смена:** номер, явка, сдача, локомотивы[], поезда[], следование пассажиром[], заметки, признаки; производные — время работы, расчёт заработка, время отдыха (домашний/в ПО, минимальный/полный).
- **Месяц:** список маршрутов, итоги (отработано, сверх, праздничные/обычные), нормы (на месяц / на дату / отработано), фильтр и сортировка.
- **Статус смены:** current / upcoming / rest / empty.
- **Справочники:** серии локомотивов (нормы), станции (нормы).
- **График/календарь:** паттерн смен, выбранный день, отвлечения (отпуск и т. п.).
- **Подписка:** план (free/pro), дата продления/истечения, дни до конца.
- **Аккаунт:** профиль (VK ID, email), статус синхронизации, состояние авторизации (login/register/recover/sent, ошибки).
- **Синхронизация:** флаг synced на каждом маршруте.

## 9. Ассеты

- **Шрифты:** Inter (400–800) и JetBrains Mono (400–700). В макетах — Google Fonts; в приложении подключить как локальные/системные ресурсы.
- **Иконки:** собственный набор SVG в `src/icons.jsx` (`Ic*`). Заменить на эквиваленты иконочной системы целевого проекта.
- **Логотип:** `IcLogo` — графика «М» из вертикальных штрихов; есть отдельная секция логотипа в проекте.
- **Фото профиля:** из VK ID (внешний источник).
- Растровых изображений нет — всё векторное/CSS.
