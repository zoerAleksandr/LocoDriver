## Общие правила

**Цвета** — только `tokens.js`: `accent` — действия; `warning` — «нет координат», расхождение длины; `success` — «координаты есть», выполненный шаг, `Switch` вкл; `danger` — только удаление и ⊖ в режиме правки. Прозрачные подложки через `hexToRgba` — те же формулы, что в A«Общие правила» (плашки @12%, квадрат-иконка @14%, кружок шага `success` @15%, ореол метки `accent` @20%, обводка «+» `accent` @50%).

**Кнопки** (`IpBtn`), sans, letter-spacing −0.2, gap иконка–текст 8:

| Вариант | Фон / текст | Размер |
|---|---|---|
| primary | `accent` / `accentInk` | h50, r12, padding 0 16, 17/600 |
| secondary | `bgSubtle` / `accent` | h50 (в карточке координат h44, 15), r12, 16/500 |
| plain | прозрачный / `accent` | h по месту (32–44), 15/500 |
| destructive | прозрачный / `danger` | h44, 15/500, `IcTrash` 16 |

Disabled: primary/secondary — фон `bgSubtle`, текст `textFaint`; plain — текст `textFaint`.
SwiftUI: `.buttonStyle(.borderedProminent)` / `.bordered` с `.controlSize(.large)` и `.tint(accent)`, либо свой `ButtonStyle` с этими размерами.

**Шторка** (`IpSheet`) — `.sheet` + `presentationDetents`:
- Редактор плеча: `.large`, верх шторки на 64 от верха экрана. Автоподбор — второй `.sheet` поверх, `.large`, верх 74. Шторка станции — по содержимому: `.presentationDetents([.height(h)])` (или `.medium, .large`).
- Фон `bg`, верхние углы 18, тень `M.shadow.sheet`. `.presentationCornerRadius(18)`, `.presentationDragIndicator(.visible)` — грэббер 36×5, `borderStrong`, отступ 8.
- Шапка h44, отступ сверху 4, padding 0 16. Сетка: `[min max-content, 1fr] [auto] [min max-content, 1fr]` — заголовок строго по центру, при нехватке места — многоточие.
  - слева «Отмена»: sans 16/400 `accent`;
  - заголовок: sans 17/700 `text` (`M.t.navTitle`);
  - справа действие: sans 16/600 `accent`; неактивное — `textFaint`.
  - SwiftUI: `NavigationStack` внутри шторки, `.toolbar { ToolbarItem(.cancellationAction) … ToolbarItem(.confirmationAction) … }`, `.navigationBarTitleDisplayMode(.inline)`.
- Подзаголовок (только автоподбор): sans 12 `textMuted`, по центру, padding 0 24 6, переносится.
- Тело прокручивается, padding 6 16 34 (с футером — 6 16 20).
- Футер (только предпросмотр автоподбора): padding 10 16 34, сверху линия 1 `border`, gap 10. SwiftUI: `.safeAreaInset(edge: .bottom)`.
- «Отмена», свайп вниз = отмена без сохранения. Если есть несохранённые изменения — `.interactiveDismissDisabled(true)` + подтверждение (поведение как в Android: закрытие = отмена).
- Scrim каждого уровня `rgba(0,0,0,0.45)` — второй уровень затемняет первый (в SwiftUI это делает система).

**Строка-поле** (`IpFieldRow`) внутри `Card`:
- мин. высота 56, padding 8 16, gap 10;
- лейбл sans 12 `textMuted` (в фокусе `accent`), отступ до значения 2;
- значение sans 16/600 `text`, letter-spacing −0.2, межстрочный 1.25, переносится по словам (длинные названия не обрезаются);
- плейсхолдер sans 16/400 `textFaint`;
- leading `IcMapPin` 18 `accent` (у пустого — `textFaint`); суффикс «км» sans 13 `textMuted`;
- фокус: без рамки; лейбл `accent` + системный курсор `accent` (`.tint(accent)`); очистка — `xmark.circle.fill` 18 `textFaint` справа.
- SwiftUI: `VStack(alignment: .leading, spacing: 2) { Text(label); TextField(…, axis: .vertical) }` в `Section` / своей карточке.

**Круглая галка** (`IpCheck`) 22: вкл — круг `accent` + белая ✓ 13 (stroke 3.2); выкл — обводка 1.5 `borderStrong`; заблокирована — круг `textFaint` + белая ✓. SF Symbols: `checkmark.circle.fill` / `circle`.

**⊖** (`IpMinusBadge`): круг 22 `danger`, белая черта 10×2. SF: `minus.circle.fill`.

**Тост** (`IpToast`): left/right 12, bottom 34 (над home indicator), мин. высота 50, радиус 14, фон `cta`, текст `ctaInk` sans 14/500, межстрочный 1.35, padding 8 8 8 16, тень `floating`. Кнопка «Отменить» sans 15/600, h34, padding 0 10; цвет — в светлой теме `M.dark.accent` #33BFFF, в тёмной `M.light.accentHover` #0091D9 (контраст на инверсном фоне, как в Android). Держится 6 с. SwiftUI: оверлей `.overlay(alignment: .bottom)` с `.transition(.move(edge: .bottom).combined(with: .opacity))`.

**Спиннер** (`IpSpinner`) — `ProgressView()`: 8 лепестков, `textMuted`, 18–20. **Прогресс** (`IpProgress`) — `ProgressView(value:)`: h4, r2, трек `bgSubtle`, индикатор `accent`. Если прогресс неизвестен — анимировать значение по шагам (1/3 → 2/3) или использовать неопределённый бар своей вёрсткой.

## 2. Редактор плеча · `02`–`08`
`.sheet(.large)`. Шапка: «Отмена» — «Новое плечо» / «Редактировать плечо» — «Добавить» / «Сохранить». «Добавить» неактивно (`textFaint`), пока не заполнены обязательные поля (`02`).

Сверху вниз:
1. **Поля** — две карточки, gap 12:
   - `Card`: «От станции» / `Sep` inset 44 / «До станции» — строки-поля с `IcMapPin`, автодополнение как сейчас; плейсхолдер «Начните вводить название»;
   - `Card` с двумя колонками (flex 1 / 1, между ними вертикальная линия 1 `border`, отступы 10 сверху/снизу): «Расстояние, км» (плейсхолдер «—»), «Доплата за пробег, ₽/км». Лейбл второго поля может переноситься.
2. **Только для нового плеча:** `Card` + `SwitchRow` «Создать плечо в обратном направлении» (mt 12, вкл по умолчанию) + `SectionNote` «Промежуточные станции тоже скопируются — в обратном порядке.» Логика разворота → A§2.
3. **`GroupHead` «ПРОМЕЖУТОЧНЫЕ СТАНЦИИ · N»**, mt 22. Справа plain-кнопка sans 15 `accent`: «Изменить» (400) / в режиме правки «Готово» (600). При пустом списке кнопки нет. SwiftUI: локальный `@State var editMode: EditMode` + `.environment(\.editMode, $editMode)` для списка станций.
4. **Блок станций:**
   - **Пусто (`02`, `03`)** — `Card`, padding 16:
     - текст sans 14, lh 1.45, `textMuted`;
     - колонка кнопок, mt 14, gap 8: primary «Найти автоматически» (`IcSearch` 18, full) и secondary «Добавить вручную» (`IcPlus` 18, full);
     - нет крайней станции → primary disabled + подпись sans 12 `textMuted` по центру, mt 10: «Для автоподбора укажите обе крайние станции».

### Схема участка (`IpLine` / `IpStopRow`)
Геометрия и правила — как A«Схема участка», с отличиями:
- padding карточки 4 10 4 6; колонка линии 32; пунктир 1.5 `borderStrong`; точки: крайняя 14 `text`, станция 12 (`surface` + 2 `borderStrong`), О.П. 8 (`surface` + 1.5 `textFaint`).
- Строка: мин. h 56 (О.П. 48), padding 8 4, gap 10, линия снизу 0.5 `border` (кроме последней).
- Название: станция sans 15/600 `text`, О.П. sans 14/500 `textMuted`; lh 1.25, ls −0.2, `.lineLimit(2)` + `.truncationMode(.tail)`; перенос по словам и дефисам.
- Подстрока mono 11/500 `textFaint`: «отправление» / «прибытие» / «станция · ЕСР 030329» / «О.П.»; «нет координат» `warning`; «уже в списке» `accent`. Части не рвутся.
- Км справа mono 13/500 `textMuted`, «25,1 км»; нет км — «—» `textFaint`; отправление «0 км», прибытие — целое.
- View-режим: у промежуточных `IcChevronRight` 14 `textFaint`, у крайних — пустые 14; крайние не нажимаются.

### Edit mode (`07`)
- Слева после колонки линии — ⊖ 22 (`danger`) у промежуточных; у крайних — пустые 22. Тап по ⊖ → **сразу убрать**, без подтверждения, тост «Станция убрана» + «Отменить» (как Android ✕). Системный swipe-to-delete (`.onDelete`) тоже допустим с тем же результатом.
- Справа ≡ (3 линии, 20, stroke 1.8, `textFaint`; при перетаскивании `accent`) в зоне 36×40. У крайних — пустые 36.
- Поднятая строка: фон `surface`, r12, тень `floating`, масштаб 1.03, линия в её колонке скрыта. Крайние не перетаскиваются; промежуточные нельзя поставить до отправления или после прибытия. SwiftUI: `.onMove` в `List` с `.moveDisabled(isTerminal)`, либо `draggable`/`dropDestination` при кастомной вёрстке.
- **Вставка** (`IpInsertRow`, h30) между каждой парой соседних строк — как A«Режим правки»: кружок 22 `surface`, обводка 1.5 `accent` @50%, `IcPlus` 12 `accent`; подпись «вставить» sans 12/500 `textFaint`, отступ 10; активная — кружок залит `accent`, «Вставить станцию сюда» `accent`. Тап → «Новая станция» с этой позицией.
- Км при перестановке не пересчитываются. «Готово» выходит из режима; в плечо изменения попадают только по «Сохранить».
- `danger` в edit mode — только ⊖.

## 3. Шторка станции · `09`–`15`
`.sheet` по высоте содержимого (`.presentationDetents([.height(h), .large])`) поверх редактора. Шапка: «Отмена» — «Станция» / «Новая станция» — «Готово» (неактивно при пустом названии). Тело padding 6 16 34, колонка gap 12.

1. **Название** — `Card` со строкой-полем «Название».
   - Новая станция (`14`): поле в фокусе — лейбл `accent`, курсор 2×19 `accent`, справа очистка `xmark.circle.fill` 18 `textFaint`.

## Новые токены
**Не понадобились.** Использованы `accent`, `accentSoft`, `accentInk`, `accentHover`, `warning`, `success`, `danger`, `cta`, `ctaInk`, `bg`, `bgSubtle`, `surface`, `surfaceAlt`, `border`, `borderStrong`, `text`, `textMuted`, `textFaint`; радиусы `M.r.cardIOS` 18, `M.r.sheetIOS` 18, `M.r.md` 12, 10 (квадрат-иконка), 14 (тост, action sheet, «Выбрать» на карте — как CTA в `ShouldersSheet`), 20, 22; тени `sm` / `md` / `floating` / `fab` / `sheet`.
Прозрачные подложки — `hexToRgba` от существующих цветов (см. «Общие правила»), не новые токены.
Белый (#FFFFFF) на ⊖ и круглой галке — системный цвет глифа SF Symbols поверх заливки, не токен палитры.
