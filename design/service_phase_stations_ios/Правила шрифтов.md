# Правило использования шрифтов — «Машинист»

Два шрифта: **Inter** (sans) и **JetBrains Mono** (mono). Разделение — не по автору данных (пользователь/система), а по **типу контента**.

## Mono (JetBrains Mono) — для идентификаторов и значений
Используется для всего, что нужно **точно считать, сверить или сопоставить в столбик**:
- Числа: время (явка/сдача, отдых), деньги/расчёты, нормы часов, статистика, счётчики.
- Идентификаторы, даже буквенно-цифровые: номер маршрута, **серия и номер локомотива** («ВЛ10-1456»), номер поезда, номер вагона.
- UPPERCASE-заголовки групп карточек («ОСНОВНЫЕ ДАННЫЕ») — уже так делается, оставить.

Признак: если значение можно перепутать посимвольно (0/O, 1/l) или оно выравнивается в колонку — Mono.

## Inter (sans) — для языка и интерфейсных подписей
Используется для всего, что **читается как язык**, а не сверяется как данные:
- Заголовки экранов, лейблы, подсказки, кнопки, пункты меню.
- Имена собственные и названия: **название станции** («Москва-Товарная»), название серии словами, если есть.
- Свободный текст пользователя: заметки, комментарии.
- Любая проза/описания.

## Пограничные случаи — решать по этому принципу
- «ВЛ10-1456» (серия+номер локомотива) → **Mono** (идентификатор, не проза).
- Название станции → **Inter** (имя собственное, не идентификатор).
- Номер маршрута/поезда/вагона → **Mono**.
- Свободная заметка машиниста → **Inter**, даже если внутри она содержит числа (числа внутри предложения не выделять отдельным шрифтом).

## Не менять
- Не привязывать выбор шрифта к тому, кто ввёл значение (пользователь vs система) — только к типу контента (идентификатор/значение vs язык).
